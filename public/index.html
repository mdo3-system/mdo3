help APIキーの取得手順（所要時間：約3分・無料枠内で利用可能）

STEP 1
Google Cloud Console へアクセス

Googleアカウントでログインし、コンソール画面を開きます。

open_in_new Consoleを開く
STEP 2
プロジェクトを作成

上部プロジェクト選択バーから「新しいプロジェクト」を作成します（例: mdo3-wrc-calc）。

STEP 3
必要なAPIを有効化

左メニュー「APIとサービス」→「ライブラリ」から以下を検索して「有効にする」をクリックします：

  • Google Sheets API (必須)
  • Google Drive API (推奨)
STEP 4
APIキーを発行 & コピー

「認証情報」→「＋認証情報を作成」→「APIキー」を選択。発行された AIzaSy... から始まる文字列をコピーします。

※「キーを制限」でGoogle Sheets APIのみに限定設定するとより安全です。
STEP 5
上記フォームに貼り付けて保存

上の入力欄にペーストして「キーを保存」を押せば完了です。WRC造の全ツールが即座に利用可能になります。
